# SG Typer Studio

**SG Typer Studio** — автономный редактор для перевода и вёрстки манги, комиксов и манхвы. Он объединяет рабочий процесс TypeR, редактирование PSD/PSB и IDML, типографику, работу со звуковыми эффектами, ретушь, кисти Photoshop, пакетную обработку страниц и необязательные AI-функции.

**Разработчик: BOT.**

Программа основана на идеях и исходном коде открытых проектов:

- [TypeR — ScanR/TypeR](https://github.com/ScanR/TypeR);
- [Typer Studio — ScanR/TypeR-Studio](https://github.com/ScanR/TypeR-Studio);
- [PhotoCraft — storytold/photocraft](https://github.com/storytold/photocraft).

> SG Typer Studio — самостоятельная версия, а не просто переименованная копия. В ней изменены рабочее пространство, кисти, Actions, Healing Brush, Navigator, локальные и сетевые AI-провайдеры, хранение профиля и Windows-сборка.

## Основные преимущества

- **Полный цикл перевода комикса:** открытие страниц, очистка фразировок, вставка перевода, выравнивание, подбор шрифтов, редактирование SFX и экспорт главы.
- **Настоящий многослойный редактор:** текстовые и растровые слои, группы, пиксельные и векторные маски, clipping masks, эффекты и отдельные Curves adjustments.
- **PSD без безусловного flatten:** неизменённые слои, текстовые engine data, маски и эффекты по возможности сохраняются в исходном виде.
- **Кисти Photoshop `.abr`:** не просто список пресетов — sampled и computed tips реально участвуют в рисовании, History и Actions.
- **Продвинутая ретушь:** Content-Aware Fill, Spot Healing и отдельная Healing Brush с gradient-domain blending и вычислениями в Worker.
- **Гибкая автоматизация:** записываемые наборы Actions, отключение отдельных шагов, собственные сочетания клавиш и локальное хранение библиотеки.
- **Выбор AI-провайдера:** Google, fal.ai, OpenRouter, OpenAI-compatible/local endpoint, Adobe Firefly или обработка на устройстве.
- **Локальное рабочее пространство:** интерфейс desktop-приложения встроен в установку и не скачивается с сайта при каждом запуске.
- **Перенос существующего профиля:** документы, настройки, шрифты и хранилища TypeR Studio не теряются при переходе на SG Typer Studio.

## Запуск

### Готовая установка

Основная desktop-сборка рассчитана на **Windows x64**. Установщик NSIS создаётся с именем:

```text
SG Typer Studio-Setup.exe
```

Установщик сохраняет пользовательские документы и профиль при удалении программы.

## Документы и форматы файлов

| Формат | Открытие | Сохранение и особенности |
|---|---:|---|
| **PSD** | Да | Полноценное сохранение слоёв, текста, масок и поддерживаемых эффектов |
| **PSB** | Да | Для больших документов; автоматически используется при необходимости |
| **PNG** | Да | Экспорт страниц и пакетный экспорт |
| **JPEG** | Да | Экспорт с настройками пакетного сохранения |
| **WebP** | Да | Экспорт, если кодировщик поддерживается платформой |
| **IDML** | Да | Страницы открываются во вкладках; редактирование текста и сохранение IDML |
| **INDD / INDT** | Да, через встроенный WASM | Сохранение выполняется как IDML, который InDesign может открыть и сохранить обратно |
| **ABR** | Импорт в Brushes | Создание постоянной библиотеки кистей |
| **TBR** | Импорт панели инструментов | Настройка набора инструментов Photoshop |
| **ZIP / JSON TypeR** | Импорт | Стили, шрифты и комплекты TypeR |
| **JSON Actions** | Хранение библиотеки | Наборы и действия сохраняются локально; desktop также имеет папку Actions |

### PSD/PSB

- чтение и запись выполняются локально через `ag-psd`;
- длинные операции по возможности выполняются в PSD Worker;
- поддерживаются группы, текст, растровые слои, маски, векторные маски, связанные файлы и layer effects;
- поддерживаемые Curves adjustments можно редактировать отдельно;
- неизменённые исходные данные слоя сохраняются без лишней перерисовки;
- исходные записи adjustment-слоёв сохраняются вместе с документом;
- документ можно открыть в установленном Photoshop.

### Мультистраничные проекты

- открытие отдельного файла или папки со страницами;
- вкладки документов и переход между страницами;
- список недавних файлов;
- автоматическое восстановление открытых документов;
- пакетная обработка и сохранение главы;
- страницы IDML/INDD открываются как связанный комплект.

- встроенные Hard Round и Soft Round пресеты;

## Generative Fill и локальная обработка

Generative Fill работает с выделением и позволяет удалить текст или перерисовать область по prompt. Предусмотрены настройки модели, размера, стоимости, отмены задания и обработки ошибок.

### Провайдеры

- **Google Gemini** — поддерживаемые image-модели Gemini/Nano Banana;
- **fal.ai** — Nano Banana, FLUX Kontext, Ideogram и другие настроенные модели;
- **OpenRouter** — OpenAI-compatible chat completions с возвратом изображения;
- **OpenAI-compatible / local** — собственный endpoint и модель, API key необязателен;
- **On this device** — LaMa Manga в Worker; в desktop также доступны поддерживаемые локальные FLUX-модели;
- **Adobe Firefly** — в desktop через изолированную Adobe-сессию главного процесса, с поддерживаемыми Firefly, GPT Image и Gemini partner models.

### Локальные операции без AI-аккаунта

- Content-Aware Fill;
- Spot Healing;
- Healing Brush;
- LaMa Manga после получения необходимых model files;
- локальные OpenAI-compatible серверы пользователя;
- локальные FLUX-модели после явного согласия на скачивание.

Сетевые провайдеры расширяют выбор моделей и сценариев обработки, а локальные модели и алгоритмы выполняют работу прямо на компьютере.

## Сохранение профиля и приватность

- Открытые документы, слои, маски, History, вкладки и zoom сохраняются в IndexedDB.
- Пиксели хранятся отдельно от компактных документных записей.
- Библиотека ABR и sampled alpha хранятся в IndexedDB.
- Actions, Styles, workspace, shortcuts и настройки сохраняются локально.
- Недавние файлы и пользовательские шрифты восстанавливаются.
- При первом запуске существующий профиль `%APPDATA%/TypeR Studio` копируется в `%APPDATA%/SG Typer Studio`; старый профиль не изменяется.
- Кэши и удалённый интерфейсный контент при миграции не копируются.
- Desktop использует встроенный renderer без Service Worker, PWA manifest и удалённой загрузки интерфейса.
- **Справка → Проверить обновление…** скачивает новые Windows-версии из GitHub Releases с показом changelog, прогресса и подтверждением установки.

Сетевая активность возможна только для явно предусмотренных функций: What's New/GitHub, выбранного AI-провайдера, Adobe, получения моделей, проверки цен и других запрошенных пользователем операций. Основное редактирование выполняется локально.

## Чем SG Typer Studio отличается от Typer Studio

SG Typer Studio развивает возможности TypeR и Typer Studio, добавляя удобные инструменты для ежедневной работы с комиксами, расширенную автоматизацию и гибкую интеграцию с внешними сервисами.

| Область | SG Typer Studio | Практическое отличие |
|---|---|---|
| **Кисти** | Постоянная Brushes library с поиском, группами, ABR computed/sampled tips и реальным применением в движке | Можно установить Photoshop-кисть и рисовать именно её формой, а не только увидеть пресет |
| **ABR в History/Actions** | Sampled alpha входит в мазок, Undo/Redo и записанные Actions | Импортированная кисть участвует в полном рабочем цикле |
| **Actions UX** | Независимые disclosure-состояния, выбор без сворачивания, shortcuts, JSON library, отключение шагов | Большие наборы удобнее просматривать и повторно использовать |
| **Healing Brush** | Отдельный инструмент с gradient-domain blend, Worker, live preview и компактным replay | Не только удаление точки, но и перенос текстуры с сохранением освещения/цвета цели |
| **Spot Healing** | Дополнительно перенесены защита пустого слоя и распознавание screentone | Меньше чёрных или белых артефактов на типичных страницах манги |
| **Smudge** | Finger Painting, Sample All Layers и оптимизация без лишнего snapshot/readback | Более быстрый первый мазок в текущей архитектуре |
| **AI-провайдеры** | Дополнительно OpenRouter и произвольный OpenAI-compatible/local endpoint | Можно подключить собственный сервер или другую совместимую модель |
| **Navigator** | Миниатюра, viewport, zoom и документные scrollbars | Удобнее работать с длинными webtoon-страницами |
| **Curves** | Точки, карандаш, каналы, отдельный adjustment и PSD round-trip | Коррекция без обязательного разрушения исходных пикселей |
| **Профиль** | Миграция TypeR Studio с сохранением старого профиля | Переход не требует ручного переноса IndexedDB и настроек |
| **Оболочка** | Встроенный локальный UI и управляемые обновления через GitHub Releases | Интерфейс остаётся локальным, а новая версия скачивается и устанавливается по подтверждению пользователя |
| **Бренд и совместимость** | SG Typer Studio, BOT, отдельный профиль и legacy protocol | Новая идентичность без потери связи с существующим TypeR plugin |
